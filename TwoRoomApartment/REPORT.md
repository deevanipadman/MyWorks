## How to run
- Start a local server in the project root (e.g. `python -m http.server 8000`) and open `http://localhost:8000`.

## Main features
- Two separate rooms with floors, ceilings, and walls with thickness.
- Doorway connecting rooms.
- 3–5 furniture items per room (sofa, table, lamp, bed, chair, nightstand).
- At least three materials used: wood, metal, glass.
- Camera interactivity via OrbitControls and keyboard (WASD / arrows).
- Lighting: hemisphere, directional and point lights with shadows.
- Animation: rotating ceiling fan.

## Assets & Libraries
- Three.js (module import from CDN)

## Known issues / missing features
- The doorway is simulated rather than using boolean CSG subtraction.
- No collision detection — camera can pass through thin walls.
